## 云端与 Mac 模式

本版本保留本地模式，并增加云端密码登录、设备配对、持久信箱和 Mac 出站执行。它不提供公网入口，不迁移旧工作区。模型配置在 Mac 本地修改，云端展示脱敏摘要。

实际验证和未验收项见 [云端验证记录](cloud-verification.md)。支持私有访问不等于已在用户服务器部署，也不等于桌面安装包或全部功能对齐已完成。

## 替代旧版实际使用前的验收条件

1. 每项保留能力具有可重复的行为验收，不以“有页面”或“有字段”算完成。
2. 使用隔离的旧数据副本验证完整映射、ID 关联、恢复边界和回滚，不迁移活跃授权。
3. Codex 和 Claude Code 分别完成真实任务与权限交互验证。
4. 安装包在无开发环境的 Mac 完成启动、退出、恢复和升级测试。
5. 分发安装包或构建包前，核查新实现来源及所包含依赖的完整第三方声明。
