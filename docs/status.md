## 替换条件

1. 每项保留能力具有可重复的行为验收，不以“有页面”或“有字段”算完成。
2. 使用隔离的旧数据副本验证完整映射、ID 关联、恢复边界和回滚，不迁移活跃授权。
3. Codex 和 Claude Code 分别完成真实任务与权限交互验证。
4. 安装包在无开发环境的 Mac 完成启动、退出、恢复和升级测试。
5. 新实现来源和第三方声明经过核查后，再决定替换主分支。
