# 云端信箱与 Mac 工作区

Jarvis 让 Mac 保持唯一可写业务工作区。云端负责用户身份、设备身份、持久命令信箱和只读快照，不创建第二个可写 Task 数据源。这样，审批、模型请求、CLI 进程和文件仍在同一个故障域内。

```text
浏览器 ── 本机回环地址与 SSH 通道 ── cloud
                                     │ 账户、信箱、只读快照
Mac 出站 worker ──────────────────────┘
  │
  └─ 唯一 Workspace ── 模型 API / 本机 Codex / 专用任务目录
```

## 命令与业务状态不同

`shared/relay.ts` 定义封闭命令集合，不接受任意 HTTP 转发、shell、cwd 或环境变量。云端 `202` 只表示信箱已保存操作。Mac 应用业务方法后才回传终态回执。取消操作被应用也不等于进程已退出，实际任务状态仍由 Mac 确认。

Mac 先将命令 ID 和摘要以 `started` 写入持久 journal，再调用业务入口，最后写终态。重启发现只有 `started` 时记为 `unknown`，不重新调用业务。相同 ID、相同摘要重传已有回执，摘要不同则拒绝。这里保证每个 ID 最多进入一次业务调用，不承诺分布式 exactly-once。

业务写入与回执写入不是同一个事务。若刚写 `started` 就崩溃，业务可能尚未发生也可能已发生，因此未知结果需要人工核实。未知命令释放信箱队列，后续取消可以送达。后续业务仍检查真实任务版本、授权和状态。

快照使用持久递增 revision。旧 revision、异摘要的相同 revision 和被撤销设备的旧代际不能覆盖新状态。目录只发布 `mac-task:任务ID` 别名。命令和快照有容量限制，超限显式拒绝，不静默删除去重记录或截断结果后宣称完整。

## 断线与启动权限

remote 模式默认禁止启动外部工作。认证同步续租后，Mac 使用本机单调时钟检查有效期，并扣除网络请求耗时。当前云端每次发放 15 秒租约，协议拒绝超过 30 秒的租约。模型注意力请求、主会话请求和 CLI 真正启动前都检查租约。

断线、撤销或租约过期时，系统禁止新启动并尝试中止在途工作。它不是即时撤销，也无法保证外部供应商没有处理已经收到的请求。未确认进程退出时保留中断和核实路径，不以离线代替取消成功。remote 模式下，崩溃中的消息处理不会自动再次调用付费模型。

## 身份与数据边界

首版只支持可信单用户、本机回环和 SSH 通道。cloud 存储带随机盐的 scrypt 密码验证值、会话摘要和设备凭据摘要。设备使用可撤销的 256-bit 随机 bearer。配对码短时且一次有效。浏览器会话与设备 API 权限分离，浏览器写操作检查 Host、Origin、JSON、自定义请求头和会话 CSRF。

bearer 保密依赖本机、服务器及 SSH 通道。它不提供设备请求的密码学防重放，命令去重不能替代凭据保密。公网、多租户或抗云端失陷不在当前安全保证内。

新的 remote 工作区会话、记忆、任务、规则和文本交付会保存到 cloud。API Key、模型服务目标、原始 CLI 日志和项目文件不参与同步。云端模型设置只读，本地仍保留九类模型配置与独立注意力配置。

上行投影检查已知密钥和本地路径，降低误传风险，不是完整 DLP。用户写入的未知秘密仍可能进入消息或结果。Codex `workspace-write` 不是虚拟机，也不代表系统级只读隔离。不要接收不可信第三方任务，不要把本机敏感文件的保护寄托于提示词。

## 本地模式仍独立

`npm start` 继续默认本地模式，使用 `.jarvis/` 和端口 `4320`。`npm run worker:start` 显式使用新的 remote 工作区，默认 `.jarvis-worker/` 和端口 `4322`。cloud 默认 `.jarvis-cloud/` 和端口 `4321`。三者不共享业务数据库，不自动迁移旧数据。

实现中的身份边界和密码存储取舍参考 [OWASP 密码存储指南](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) 与 [会话管理指南](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)。SSH-only 是当前范围，不应把该 Cookie 或 HTTP 配置直接复制到公网部署。
