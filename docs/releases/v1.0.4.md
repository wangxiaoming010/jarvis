# Personal OpenBot Group 1.0.4

本版让「当前工作」更清晰：同一目标只显示一张卡片，切换到 Bot 私聊后，仍可查看它在各个会话中的工作，并回到来源对话。相较已公开的 v1.0.2，本版也包含 Bot 性格、长期偏好与后台记忆整理更新。

## 更新内容

- 「当前工作」按目标合并关联的执行记录，不再把目标与本轮任务重复计数；卡片展示负责人、当前执行、最新进展和下一步，详细记录按需展开。
- 群聊展示本群工作；Bot 私聊展示该 Bot 在所有会话中尚未结束的工作。卡片标明来源，可一键回到群聊或其他来源对话，切换会话不影响后台执行。
- 保留「停止本轮工作」，并增加「结束目标」及确认提示。即使目标正在等待后续行动，也可明确结束，避免继续自动推进。
- 所有 Bot 共用礼貌亲和、简洁、诚实、有判断、对承诺负责的性格主线；角色描述决定各自擅长和关注的内容。主会话与本机执行使用同一套表达原则，提示按当前职责和事件组织。
- 长期偏好与历史事实分开保存。来自用户的长期表达偏好可跨对话持续生效，同时保留来源，不代表获得新的执行权限。
- 新增后台记忆整理：群里无需 Bot 回复的人类消息，也可留下有来源的偏好和事实。整理不发言、不执行任务，不把其他 Bot 的话记成用户的话，不改写用户已更正或删除的记忆，不记录疑似密钥。
- 移除旧版群路由与兼容对话入口，并按职责整理后台模块、测试和验证脚本。

## 下载与升级

- `Personal-OpenBot-Group_1.0.4_arm64.dmg`：适用于 macOS 12 或更高版本的 Apple Silicon Mac。
- 安装包使用 Developer ID 签名并完成 Apple 公证；可通过 `SHA256SUMS` 核对下载文件。
- 升级前退出旧版，将新版拖入 Applications。
- 应用标识和数据目录保持不变，现有数据自动迁移（新增记忆类型与记忆整理记录）。建议先备份应用数据；不要用旧版直接打开迁移后的数据库。

记忆整理使用设置中的注意力模型（未单独设置时使用对话模型），每个 Bot 每批消息调用一次，会增加少量模型用量；未配置模型时不进行整理。

安装包包含 Node.js、本地服务与 Bridge。Codex CLI 或 Claude Code 及其账号配置仍需自行准备。本版提供 macOS Apple Silicon 安装包，不提供自动更新。
