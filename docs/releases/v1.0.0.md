# OpenBot 1.0.0

首个公开版本。桌面应用名称为 **OpenBot**。

## 下载与安装

- `OpenBot_1.0.0_arm64.dmg`：适用于 macOS 12 或更高版本的 Apple Silicon Mac。
- 打开磁盘映像，将 OpenBot 拖入 Applications。
- 使用 `SHA256SUMS` 核对下载文件的 SHA-256。

本版仅提供已验证的 macOS Apple Silicon 安装包。

## 主要功能

- 与 Bot 私聊，或创建群组进行多人 Bot 协作。
- 每个 Bot 独立判断消息、维护长期记忆、调度任务并验收结果。
- 目标独立于执行任务保存，支持离线安排、定时跟进、条件等待、截止时间与需要所有者决策的提醒。
- 支持群聊与私聊之间关联工作，以及 Bot 之间可追踪的委托、接受、交付、验收与取消。
- 项目要求和决策按版本记录；交付物经过内容核验、接受和应用检查，避免旧要求或过期证据通过验收。
- 长期记忆支持按问题检索、更正和失效；紧急消息可优先处理，代码任务支持独立 Git worktree 与资源冲突保护。
- 支持 DeepSeek 及其他主流或 OpenAI 兼容模型，在设置页填写 Key 并选择模型。
- 连接本机 Codex CLI / Claude Code，支持异步任务、任务管道、会话续接和执行接力。
- 持久化 Bot、群组、聊天与任务；提供真实任务进度、异常观察和权限交互。
- 支持交互卡片、表单、图表、Markdown 和中文输入法。
- 关闭窗口后继续在菜单栏／托盘运行；明确退出才停止后台。

## 首次使用

1. 在设置中配置对话模型与 API Key；注意力模型可以跟随主模型或单独选择。
2. 安装并登录可用的本地 Codex CLI 或 Claude Code。
3. 创建 Bot，与其单独聊天，或自行创建群组。

安装包包含 Node.js、本地服务与 Bridge，无需另开终端启动后台。
模型服务费用和本地 Agent 的账号由使用者自行配置；连接中断后结果未知的工作不会自动重跑。
当前面向单所有者本机使用，不提供多人远程部署或自动更新。
本版包含现有数据库的自动迁移；升级前建议备份应用数据。
