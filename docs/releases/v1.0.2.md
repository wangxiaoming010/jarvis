# Personal OpenBot Group 1.0.2

本版减少执行权限弹窗，改善 Bot 在群聊与私聊之间的连续协作，并修复本地连接检查和群聊重复回应问题。

## 更新内容

- 新增「设置 → 执行权限」，默认使用原生自动模式，可切换逐次确认。Codex 和 Claude Code 按各自的原生机制审批操作；只读任务保持只读。工具版本不支持或任务目录不明确时，回退逐次确认。设置从下一次执行生效。
- 修复 Codex 和 Claude 连接检查相互阻塞的问题。Codex 启动握手与账号检查使用独立时限，并分别提示未安装、执行权限不足、启动超时和账号检查超时。
- 多 Bot 群聊为每条消息随机安排注意力判断的先后间隔，并补入已到达的同事回复；顺序作为辅助信息，不强制轮流发言。
- 修复 Bot 引用同事消息时错误跳过注意力判断，以及把「无需回复」之类内部判断发到群里的问题。
- Bot 可查询自己所在群的成员和历史，在已加入的私聊与群聊之间检索上下文、维护有来源的记忆，并按要求转达消息。
- 新增实时工作区查询与群组协作工具，改善 Bot 对自身资料、群成员、任务、记忆和交付物状态的查询；管理操作沿用所有者授权校验。
- 自动压缩较长的对话与工具上下文，保留原始记录和可检索来源；摘要不替代原始证据或授权。
- 改善 @ 提及、头像编辑、界面文字和文档；应用名称统一为 Personal OpenBot Group。

## 下载与升级

- `Personal-OpenBot-Group_1.0.2_arm64.dmg`：适用于 macOS 12 或更高版本的 Apple Silicon Mac。
- 安装包使用 Developer ID 签名并完成 Apple 公证；可通过 `SHA256SUMS` 核对下载文件。
- 升级前退出旧版；将新版拖入 Applications。若旧应用名称为 OpenBot，请移除旧应用副本，避免误开旧版。
- 应用标识和数据目录保持不变，现有数据自动迁移。建议先备份应用数据；不要用旧版直接打开迁移后的数据库。

自动模式可能直接批准或拒绝操作，不能保证每个敏感操作都再弹窗。实际能力仍受本地 CLI 版本、账号、模型服务和管理员策略约束；不支持时不会切换为跳过所有权限检查。

安装包包含 Node.js、本地服务与 Bridge。Codex CLI 或 Claude Code 及其账号配置仍需自行准备。本版提供 macOS Apple Silicon 安装包，不提供自动更新。
