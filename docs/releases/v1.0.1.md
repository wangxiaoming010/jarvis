# OpenBot 1.0.1

本版改善首次使用、Bot 头像与本地执行状态提示。

## 更新内容

- 未配置对话模型时，先在设置中完成模型配置，再创建 Bot 和开始协作。
- Bot 头像支持 emoji 和上传照片，可随时修改或恢复默认头像。
- 创建 Bot 时，通过带 Logo 的卡片选择 Codex 或 Claude Code；已有 Bot可修改执行工具和设备。
- 执行时使用所选工具；工具暂不可用时等待恢复，避免自动切换到其他工具。
- 本地连接不可用时，明确提示需要安装 Codex CLI 或 Claude Code，并完成对应账号登录。
- 改善聊天、任务进度与异常提示；支持通过所选执行工具的原生联网能力检索最新信息和读取网页，实际可用性取决于账号、模型服务和网络。

## 下载与升级

- `OpenBot_1.0.1_arm64.dmg`：适用于 macOS 12 或更高版本的 Apple Silicon Mac。
- 退出旧版后，将新版 OpenBot 拖入 Applications 替换原应用。
- 现有数据保留，头像数据会自动迁移。升级前可备份应用数据。
- 安装包已完成 Developer ID 签名与 Apple 公证；使用 `SHA256SUMS` 核对下载文件。

安装包包含 Node.js、本地服务与 Bridge。本地执行工具和对应账号需自行安装、配置；本版仅显示所需条件，不提供应用内安装或登录流程。

当前面向单所有者本机使用，提供 macOS Apple Silicon 安装包；不提供自动更新。
