# Personal OpenBot Group 1.0.3

本版统一 Bot 的性格与行为主线，让长期偏好稳定生效，并新增后台记忆整理：Bot 没有回复的消息，也能留下有来源的记忆。

## 更新内容

- 所有 Bot 共用同一套性格：礼貌亲和、简洁、诚实、有判断、对承诺负责；用户填写的角色决定各自擅长和关注的内容。主会话与本机执行使用同一套性格和表达原则。
- 主会话提示按「性格 → 对话职责 → 当前事件 → 所需规则」组装。打招呼等日常交流不再携带完整的验收与交付规则，只有处理执行结果或已有工作时才加入；以工作原则替代此前堆叠的禁止条款与历史案例。
- 长期偏好与历史事实分开保存。用户说「以后回答简洁一点」等长期要求，会在所有对话中持续生效，注意力判断也会参考；长期偏好只能来自用户亲口表达，不代表获得新的执行权限。
- 新增后台记忆整理：群里无需 Bot 回复的人类消息，仍可提取有价值的偏好和事实，并保留来源。整理不发言、不执行任务；不把其他 Bot 的话记成用户的话，不改写或恢复用户之后更正、删除过的记忆，不记录疑似密钥，离开群后不再从该群学习。
- 移除旧版群路由与兼容对话入口，不再生成「这件事让谁来看看？」分工卡；已发出的分工卡仍可点击。默认的每个 Bot 独立判断与协作流程不变。
- 调整源码目录结构，按职责分组后台模块、测试和验证脚本，便于后续维护。

## 下载与升级

- `Personal-OpenBot-Group_1.0.3_arm64.dmg`：适用于 macOS 12 或更高版本的 Apple Silicon Mac。
- 安装包使用 Developer ID 签名并完成 Apple 公证；可通过 `SHA256SUMS` 核对下载文件。
- 升级前退出旧版；将新版拖入 Applications。
- 应用标识和数据目录保持不变，现有数据自动迁移（新增记忆类型与记忆整理记录）。建议先备份应用数据；不要用旧版直接打开迁移后的数据库。

记忆整理使用设置中的注意力模型（未单独设置时使用对话模型），每个 Bot 每批消息调用一次，会增加少量模型用量；未配置模型时不进行整理。

安装包包含 Node.js、本地服务与 Bridge。Codex CLI 或 Claude Code 及其账号配置仍需自行准备。本版提供 macOS Apple Silicon 安装包，不提供自动更新。
