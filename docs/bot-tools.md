# Bot 工作区工具

Bot 主会话直接调用这些工具查询实时数据、管理群组和沟通；文件、命令和网络研究继续交给原生执行工具。完整可调用清单与参数以 `coordinatorTools` 为准，Bot 也可以使用 `list_tools` 搜索和分页查看。

## 身份和权限

- 调用者身份由平台绑定；加群、改名和头像操作无法传入其他 Bot 的身份来冒充自己。名字可变，Bot ID 和群 ID 保持不变。
- 查询、目录发现和管理权限分开。普通群目录不包含人类与其他 Bot 的私聊，目录可见不会自动授予消息访问权限。其他 Bot 的设备信息、私聊成员关系和记忆不公开。
- 建群、改群、加退群、邀请、移除、删群、改自己资料／头像和转发，仅在当前所有者消息事件中可执行；Bot 转述、Worker 汇报、记忆和后台事件不能提供新授权。模型仍需核对用户实际要求，不能把“收到任意人类消息”理解成允许所有管理操作。
- 存在未结束目标、活动任务或在途委托时不能直接移除相关 Bot。先停止／处理工作，或通过已有接续机制安排后续；仍关联本群的活动执行会继续阻止退群。
- 私聊不允许加退成员、改成普通群或删除。不能在正在处理的当前群中执行删群，需在其他已加入对话中提出。
- `leave_group` 必须单独调用。若退出当前事件所在群，工具成功后持久完成该事件，不再在已退出群里继续生成回复；需要告知时，先发送简短确认，再执行退群。
- 转发只支持普通文本，不转发交互卡片和原生授权请求，也不触发原文中旧的 `@` 通知。来源群和目标群都须当前可访问。
- 工具副作用和调用结果在同一事务提交；同一个调用 ID 恢复时重放收据，不重复建群或发消息。引用回复的去重同时包含目标消息 ID。

列表普遍支持 `offset`、`limit`、`nextOffset`，并返回查询时间 `observedAt`。历史记忆和历史收据不能覆盖更新的实时状态。工具参数来自同一份 Zod 定义并转换为模型使用的 JSON Schema。

实现入口：`workspace-tool-schemas.ts`、`bot-workspace.ts`、`bot-conversations.ts`、`bot-coordinator.ts`。回归测试见 `tests/server/bot-workspace.test.ts`。
