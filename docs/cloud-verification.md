## 故障与安全回归

- 相同命令 ID 重投、异摘要冲突、回执 ACK 丢失、独立进程硬退出后的 started 恢复。
- started 后、业务调用前或业务写入后失去回执，均保留 unknown，不自动重放。unknown 后仍能接收独立取消命令。
- 密码失败限流跨重启保留，会话退出后失效，设备撤销后旧代际不能继续同步。
- 未投递过期与已投递但结果不明分别处理。快照回退、同 revision 异内容和嵌套未知字段拒绝。
- 模型 Key、设备 token 和本地 bootstrap canary 不进入同步快照。任务绝对目录映射为别名，模型服务地址不上传原值。
- attention、respond、CLI 在真实发送点检查租约。过期或断线会中止在途操作，不把未确认终止标为取消成功。
- Mac 休眠导致时钟越过期限、但到期定时器尚未调度时，返回结果也不能写成待验收或新消息。

独立审查最初复现了最后一项缺口。修复增加了返回落盘前的同步租约检查，并新增 CLI 成功、CLI 错误、模型回复与注意力返回四项回归。原本地行为继续通过。独立审查在 `a547168` 复验关闭该 P1，并给出该范围内 PASS；没有用实现者自述替代复验。
